## 🛡️ ゼロトラスト・情報セキュリティ設計
1. **完全クラウド・エッジ完結（開発機・オリジンへのアクセス完全遮断）**：GitHub Pages のグローバルCDNから配信され、ブラウザメモリ内のみで解析が完結します。
