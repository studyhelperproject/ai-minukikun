# AI見抜きくん Pro (AI真贋チェッカー)

LINE・マッチングアプリの返信、クラウドワークス/ランサーズの外注納品記事、就活ES・大学レポート、メルカリ出品画像のAI作成・代筆・フェイク加工を3秒で監査する日本特化Webアプリケーション。

## 🌐 公開URL
- **GitHub Pages (24時間常時稼働)**: https://studyhelperproject.github.io/ai-minukikun/
- **ローカル・フルスタック起動**: `python app.py` (`http://127.0.0.1:8080`)

## 🔑 主な機能
1. **LINE・マッチングアプリ・外注記事AI判定**（ChatGPT特有構文・ロマンス詐欺/業者LINE誘導検知）
2. **本人文体との比較監査（Stylometry）**（普段のLINEやチャットと、提出されたレポート・長文の文体クセを比較して代筆を証明）
3. **撮影レポート・出品画像フォレンジック**（Stable Diffusion/Midjourney署名検出・スマホEXIF検査・ELA圧縮誤差ヒートマップ可視化）
4. **Word (.docx) / PDF 直接監査**（長文なのにWord保存リビジョンが1回のみ＝一括コピペ納品を自動検知）
5. **即時収益化システム**（Stripe Payment Link連携 ＋ note有料記事シリアルコード認証 `MINUKI-980-PASS` 搭載）
